# Human Resource Management System (HRMS)

## Project Overview
The Human Resource Management System (HRMS) is a web-based application developed to streamline and automate HR operations within an organization.

## Features
- Employee Management
- Department Management
- Attendance Tracking
- Leave Management
- Payroll Management
- Authentication and Login System
- Employee Dashboard
- HR Dashboard
- Reports and Analytics

## Technologies Used
- Python
- Django
- SQLite/MySQL
- HTML
- CSS
- JavaScript
- Bootstrap

## Modules
1. Employee Module
2. Department Module
3. Attendance Module
4. Leave Management Module
5. Payroll Module
6. Authentication Module

## Benefits
- Reduces manual HR work
- Improves data accuracy
- Centralized employee records
- Faster payroll processing
